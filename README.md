# 📊 CariData (React.js + Vite + Tailwind CSS)

Aplikasi **CariData** yang telah dimigrasikan ke **React 19 + Vite** dengan styling modern menggunakan **Tailwind CSS**, icon Lucide, serta tetap mempertahankan seluruh fitur unggulan:

1. **Google Sheets Master Database**: Sinkronisasi terpusat realtime antar perangkat.
2. **Kunci PIN Keamanan**: Perlindungan PIN pada level folder maupun dokumen individu.
3. **Pencarian & Filter Kolom Masif**: Search keyword instan, filter kolom spesifik, sortir, dan pagination tabel.
4. **PWA Ready**: Web App Manifest & mobile app experience.
5. **Tema Dinamis**: Auto, Light, dan Dark Mode.

---

## 🚀 Menjalankan Project

### Masuk ke folder React:
```bash
cd react-app
npm install
npm run dev
```

Server lokal akan berjalan di `http://localhost:5173/`.

### Melakukan Build Production:
```bash
npm run build
```
Hasil build produksi siap deploy akan berada di folder `react-app/dist/`.
